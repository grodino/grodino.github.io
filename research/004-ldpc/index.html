LDPC error correcting codes

February 9, 2022reportcode

Used in IEEE 802.11n-2009 (Wi-Fi), 10GB Ethernet and 5G, LDPC codes are starting to replace Turbo Codes in systems with a large code rate. In this work, we study Low-Density Parity-Check (LDPC) codes in two channels: the Binary Erasure Channel (BEC) and the Binary Memoryless Channel (BMC). To quantify the performance of the codes, we will compute their Bit Error Rate (BER) 𝑃𝑒 and Block Error Rate (BLER) 𝑃𝑏.

Implementation

The LDPC decoding and code generation were implemented in Rust. All the code is thoroughly documented and can be accessed at this address: https://github.com/grodino/ldpc. The commands associated to each figure in the report are described in the readme.md file.
